Privacy Policy

CRDC CRM - Messenger Test
Effective date: October 13, 2026

This policy describes an individually operated test integration between a Facebook Page and a local CRM Messenger inbox. The test app name does not mean this policy is issued on behalf of a company. The individual operator can be contacted at zedyhans@gmail.com.

Information processed

When Meta delivers an event from the connected test Page to this integration, the CRM may process and store:

  • Facebook Page identifiers and Page-scoped sender identifiers (PSIDs).
  • Sender names and profile-picture URLs, when Meta makes them available.
  • Incoming and outgoing message text, message identifiers, and attachment metadata or URLs supplied by Meta.
  • Postback titles or payloads, conversation timestamps, and message delivery and read statuses.
  • An optional link to a CRM client record, if the operator deliberately creates that association.

The integration does not request a sender's Facebook password. A sender identifier is not automatically treated as proof of a CRM client's identity.

Purpose

The information is used to test receiving messages, displaying conversations and available sender profiles, sending replies, and tracking delivery and read events. Please do not send sensitive personal, financial, or confidential information to the test Page.

Storage and access

Conversation and message records are stored in a local MySQL database on the operator's computer. The CRM inbox is intended for access by the operator during testing. Message text and identifiers may also appear in backend debugging logs and tunnel request inspection during testing. The test setup is not represented as a production-grade service.

Other services

Meta handles messages sent through Facebook and Messenger. During local testing, ngrok forwards webhook requests from Meta to the local backend and may process request data through its infrastructure and inspection tools. GitHub Pages hosts this policy and deletion-instructions page; it is not used to host the CRM message database.

Data processing by these providers is also subject to their policies: Meta Privacy Policy, ngrok Privacy Policy, and GitHub Privacy Statement.

Retention and deletion

The operator will manually delete locally stored test conversations, messages, and sender-profile data when testing ends, and will honor requests to delete identifiable test data. This is a manual retention commitment, not an automatic database expiration feature.

Deletion from this CRM does not delete the original conversation from Facebook, Messenger, or Meta Business Suite. Provider logs and other provider-controlled copies are subject to each provider's retention practices.

Your requests

You may contact zedyhans@gmail.com to request information about, correction of, or deletion of your test data, or to ask that the integration stop retaining future messages from you. The operator may request enough information to locate the conversation and verify that you are entitled to make the request. Do not send passwords or access tokens.

See Data Deletion Instructions for the deletion-request process.

Changes and contact

This policy will be updated if the integration's purpose, operator, hosting, or data-handling practices change. The effective date above identifies the current version.

Privacy contact: zedyhans@gmail.com.
